## Evidence completion rule

Every backfill improvement needs an original source URL (preferably exact immutable Git SHA), artifact type, what actually ran, comparison and sample denominator, seed or model information, negative controls, limitations, and the decision changed. An independent test claim additionally needs a contamination audit, external review and frozen evaluation protocol. No record is complete merely because it has a convincing README summary.
