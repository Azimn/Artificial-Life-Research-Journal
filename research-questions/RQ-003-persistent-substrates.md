# Persistent Substrates

## Question

Where can persistent organization live such that its history changes what it can become next?

## Current substrate families

JELLY Jar tests local artificial chemistry, cells, plasticity, growth, damage, repair, and environmental interaction.

Native Jar asks whether ordinary computational mechanisms such as processes, memory, files, IPC, scheduling, CPU, RAM, and disk can themselves become the physical ecology.

Pretorius Neural Network tests a plastic recurrent neural substrate.

Persona Connectome tests persistent typed topology combined with dynamic activation.

Gelatinblob tests recurrent adaptive state and synaptic-like learning mechanisms as a model-independent sidecar.

Latent Organism tests whether pretrained representational geometry can be recruited as a persistent developmental substrate when state is retained outside the renderer.

## Comparison criteria

Useful cross-substrate tests include same-origin divergence, history retention, lesion sensitivity, recovery, attractor formation, transfer, grafting, developmental individuality, and persistence after interruption.

## Current interpretation

No one substrate has been established as the answer. The program is increasingly valuable because it provides multiple radically different substrate hypotheses that can be tested under related experimental criteria.
