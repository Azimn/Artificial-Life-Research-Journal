## Registry policy

A new code repository does not automatically create a new project record. Create a new project only when there is a distinct research question, experimental lineage, or scientific boundary that would be obscured by treating it as a branch of an existing project.

Historical predecessors can receive their own records when they materially changed the research direction. Short-lived versions that were simply milestones of another project should remain inside that project's history rather than being promoted into separate projects.
