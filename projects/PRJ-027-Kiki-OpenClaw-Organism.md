# Kiki Runtime / OpenClaw Organism and Kiki Mind

The earlier runtime line asked whether an existing local agent framework could become a persistent evolving digital being rather than a tool-oriented assistant.

The proposed Kiki Runtime added episodic memory, self-state, internal cognition, emotional persistence, goals, reflection, proactive behavior, tool routing, and ongoing background activity to OpenClaw.

The important research distinction was between adding a persona to an agent and creating a continuing entity whose current behavior depends on what happened before.

This line also connected persistent identity research with practical local-agent infrastructure. It helped establish the idea that a model can be replaceable while continuity lives in a separate runtime.

## Current Kiki Mind lineage, October 2026

[Kiki Mind](https://github.com/Azimn/Kiki-Mind) now has an implemented, versioned canonical-history and derived-projection architecture, not merely a proposed local-agent design. Implementation 002 established disposable rebuildable projection state and defensive stale/unverified-read rules. Its README records a twelve-probe external hostile review without remaining blockers. Implementation 003 introduced a Developmental Evidence Layer in which observations, self-reports, corrections, commitments, choice context, model and renderer details are evidence, while psychological interpretation remains separately derived.

The external 003 review caught a commitment-lineage defect. The corrected 003.1 implementation reports 19/19 targeted re-probes and 84/84 full tests green. These are significant source/projection integrity and engineering results, not an independently blinded demonstration of personality persistence. Candidate 004 retrieval plus Subjective Frame receipt remains design research rather than merged tested functionality.

Kiki is distinct from [Calibos Mind](PRJ-041-Calibos-Persistent-Subject.md) and [The Doctor Lives](PRJ-040-The-Doctor-Lives-Definitive-Pretorius.md). The [Game Night](https://github.com/Azimn/game-night) shared-turn interaction is an observational social coordination artifact, not a controlled cognition benchmark.
