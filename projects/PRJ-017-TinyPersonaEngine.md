# TinyPersonaEngine / Living Entity First-Person Bridge

TinyPersonaEngine tests a strict transformation from objective world state into character-relative subjective access.

The pipeline is:

candidate observations -> character-relative perceptual access -> bounded attention -> subjective experience -> memory cues and action pressures -> validated action proposals.

The architecture separates world fact, perception, belief, subjective experience, and private completion.

A central rule is that subjective completions cannot silently alter objective world state.

This project is an important bridge between Persona Engine's World Authority model and DUCK's first-person cognition.
