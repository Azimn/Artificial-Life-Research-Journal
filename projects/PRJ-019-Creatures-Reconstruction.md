# Creatures Reconstruction / PEMA-Creaturez

This project reconstructs the architecture of a classic Creatures-style artificial-life organism as a lightweight modern experimental system.

The goal is not to recreate the original game world. It is to isolate the architecture of a single creature, including neural processing, drives, perception, action, learning, development, and persistent internal change.

Creature Lab v0.1 tested long-history divergence under information asymmetry and resource competition.

Creature Lab v0.2 added bounded ontogenetic plasticity so lived experience could alter future processing rather than merely accumulate stored state.

PEMA-Creaturez became the canonical home for this line as it converged with the broader PEMA work on local processing and developmental path dependence.
