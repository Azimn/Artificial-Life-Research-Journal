# Project Janus

Project Janus was a grounded digital-intelligence testbed built around a strict separation between server truth, agent belief, action, and expressed narration.

Its core question was whether an artificial agent becomes more causally grounded when it must act against an authoritative simulated world, receive consequences, revise beliefs, and distinguish what is true from what it merely thinks or says.

The proposed experimental design used a deterministic tick engine, forced structured belief and action calls, matched control and grounded conditions, and a predeclared rubric distinguishing fabrication from interpretation.

Janus became an important conceptual donor for later World Authority, belief ledgers, first-person firewalls, and the distinction between canonical world state and subjective experience.
