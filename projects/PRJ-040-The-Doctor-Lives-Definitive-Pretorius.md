# The Doctor Lives: Definitive Pretorius Integration and Causal Audit

## Project role

[The Doctor Lives](https://github.com/Azimn/The-Doctor-Lives) is the canonical production assembly of Pretorius, not an additional subject competing to become definitive. It integrates provenance-gated identity evidence, deep history, relationships, commitments, needs, endogenous cognition, recurrent policy, consolidation and a stable chassis interface.

## Causal experiments and integration findings

The [v0.3 causal audit](https://github.com/Azimn/The-Doctor-Lives/blob/main/README.md) used matched cloned state and lesions to trace how persistent state influenced retrieval, recurrent-policy scores, selected tendencies, and renderer inputs. The repository reports that some needs, relationships, history and commitments altered downstream context without changing choice. The v0.4 bounded state-to-policy bridge was a targeted response to this failure. Recurrent reinforcement and selection have an explicit audited causal path, but it would be incorrect to infer that every implemented state variable affects action.

The later v0.5 candidate combines the accepted v0.4 path, a standalone reconstructive subjective-memory subsystem (UPPB P0 through P6D), and optional 4,096-unit Neural Convergence mechanisms. These new paths are opt-in or nonlive until their own production gates are accepted. Deep-history provenance, immutable source snapshots, append-only lived memory, schema migration and checkpoint integrity have separate contracts.

## Scientific versus product readiness

Deterministic tests, installation matrices, authoritative-source manifests and restart traces certify engineering invariants. They do not independently establish human-grade memory, generalized persona identity, or biological correspondence. The current README identifies remaining fresh-machine validation before final Gate 1 acceptance.

## Cross-project boundary

BioCircuit and FlyWire remain experimental mechanism donors; The Doctor Lives should not consume failed neural weights or promote source-unverified memories. Calibos can donate structural mechanisms without transferring personal/private state. Release progression continues separately from the shared scientific [four-arm study](../programs/CHARACTER_CONTINUITY_COMPARISON_PROTOCOL_V1.md).

## Vector Fly matched-state A/B and authenticity limits (2026-10-08)

[Stage 01](https://github.com/Azimn/The-Doctor-Lives/blob/main/results/vector_fly/PILOT01_RETRIEVAL_INTEGRATION_RESULTS.md) proved that an isolated *real* PretoriusBrainPort can receive source-verified external 450-event Vector Fly evidence **without changing** brain digest, autobiographical canon, lived memory or protected subject frame. [Stage 02, executed with CPU-only Ollama](https://github.com/Azimn/The-Doctor-Lives/blob/main/results/vector_fly/STAGE02_REAL_OLLAMA_DIALOGUE_RESULTS.md), generated all twelve real responses to six previously examined questions with the same small renderer. Four pairs differed; some replies invented homunculus details, mixed key-history events, echoed a question, or failed to deny an absent spacecraft. The entire original [per-case archive](https://github.com/Azimn/The-Doctor-Lives/blob/main/results/vector_fly/stage02-run37873205792/DIALOGUE_RAW_AB.json) is in Git, not merely an expiring artifact.

[Stage 03 masked review code and protocol](https://github.com/Azimn/The-Doctor-Lives/blob/main/docs/VECTOR_FLY_BLINDED_REVIEW_STAGE03.md) enables source-checked human factual and character-coherence ratings with a separate A/B coordinator key. No human judgments or independent validation have been completed. This contributes a **testable renderer-input effect and evaluation harness**, not established continuity or weights-localized identity. See the [central journal synthesis](../journal/2026/2026-10-08-vector-fly-to-definitive-pretorius.md).
