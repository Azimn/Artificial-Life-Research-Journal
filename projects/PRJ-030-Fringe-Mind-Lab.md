# Fringe Mind Lab

Fringe Mind Lab was a deliberately unconventional LLM-free cognitive-ecology experiment built in September 2026.

The architecture used private processes competing for finite processing resources, coalition formation, reconstructive memory, unresolved concerns, habit-related processing efficiency, and lossy downstream subjective language without a central universal Self.

Initial tests showed measurable differences between finite and abundant resource conditions, including changes in coalition width, threat capture, and habit cost.

Later falsification work found that some apparent complexity was explained by authored semantics and an unfunded-mutation loophole. After those issues were examined, the strongest remaining result was more modest: pressure-sensitive resource allocation could causally reorganize control in a history-dependent distributed system.

That negative refinement is central to the project's value. Fringe Mind Lab did not demonstrate surprising emergence, but it helped isolate which observed effects were structural and which were artifacts of design.
