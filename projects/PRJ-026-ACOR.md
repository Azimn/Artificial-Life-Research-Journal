# Artificial Character Organism Runtime

ACOR was a synthesis architecture created after several earlier persona and world-grounding experiments.

Its core question was whether a bounded character-organism loop could sustain identity consistency, react to world changes, remember selectively, distinguish truth from belief, and exhibit bounded agency without giving the language model ownership of the subject.

ACOR explicitly consolidated mechanisms from the Persistent Soul Memory Standard, SoulCore, Personal Cognitive Digital Twin, Three-Tier Digital Companion specifications, and grounded world experiments.

It included a deterministic state model, persona cartridge, mutable memory state, trace tooling, and milestone concepts for dream, identity, world interaction, and embodiment.

ACOR is historically important because it marks the transition from portable persona architecture toward an organism architecture. Later Persona Engine and DUCK work made that transition more explicit and experimentally rigorous.
