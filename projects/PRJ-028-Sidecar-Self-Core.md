# Sidecar Self-Core

Sidecar Self-Core was a standalone persistent adaptive control layer designed to sit beside, rather than inside, a language model.

Its core question was whether selective perception, tacit adaptation, intrinsic motivation, viability pressure, episodic memory, belief revision, recurrent state, and action selection could generate persistent behavioral organization while the language model remained an expression organ.

The implementation lineage added replay, recovery, autonomous intentions, service interfaces, declarative authoring, content-policy boundaries, and scenario tools.

This project is an important precursor to Gelatinblob and later organism work because it treated the self-like continuity problem as a control and adaptation problem rather than a prompting problem.

The project explicitly avoided claims of consciousness or sentience. Its research target was reverse-engineered psychological functionality that could be tested behaviorally.
