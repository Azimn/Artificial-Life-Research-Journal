# 2026-10-09: PHASE and PersonaForge mechanisms introduced as isolated Pretorius research

Disposition: **mechanics established; real character efficacy not yet established**.

Following the October 2026 comparative arXiv review, we created [The Doctor Lives draft PR #35](https://github.com/Azimn/The-Doctor-Lives/pull/35), with independent researcher-owned adaptations of PHASE-Tree's multi-timescale character-state mechanism and PersonaForge's selective conflict-sensitive deliberation. Neither external library was copied or enabled in the canonical cognition path.

Relevant external mechanism sources (pinned GitHub SHA): PHASE-Tree [arXiv:2608.06975](https://arxiv.org/abs/2608.06975), upstream `MemTensor/PHASE-Tree@0be378fd23c49915255406d881f2389b46b608b8` (MIT); PersonaForge [ACL Findings 2026](https://aclanthology.org/2026.findings-acl.386/), upstream `fQwQf/PersonaForge@10363f65b9649ae258854568608da7add1d6cc98` (Apache-2.0). This new implementation does NOT reproduce the external authors' benchmark results.

The research module adds an immutable identity root, mutable persona/session/moment fields, source witnesses and per-field resistance/cooldown gates. Persona changes require source-registered world attestations, but no authenticated world event interface has been connected yet. It also adds typed social/commitment/contradiction conflict selectors; the selector produces a request for extra reasoning, not an automatic LLM/tool call or a lived internal monologue.

Native Pretorius subject-frame protection was retained. A read-only adapter obtains authenticated existing identity, source-ranked memory references and relationship/commitment/concern structures; private machine-side state does not cross into the renderer. A three-arm text-conditioning plan uses the same native SubjectFrame sentences in flat vs PHASE-grouped order, with optional extra reasoning on selected critical cases. Private self-model and relationship summary canaries are explicitly tested for non-leakage.

**Executed integration:** [successful GitHub Action run 38022209246](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38022209246) passed 9 focused tests. Its real Pretorius source-tracking demonstration opened a new commitment with Henry, verified that it appeared in the session layer, then resolved it and verified that it disappeared. The immutable identity and persona remained unchanged; no new autobiographical memory was created by the adapter. This is a legitimate **session-tracking correctness** test, not an independently witnessed world result. The original frozen state would be stale after the native add and the new snapshot was current, as expected by construction.

**Generation pilot:** a no-API small-model research workflow was scheduled to produce matched flat/hierarchical/selectively deliberated responses on four preregistered prompts; case list and blind rubric are in [PR #35](https://github.com/Azimn/The-Doctor-Lives/pull/35). Its first local model mirror returned HTTP 404 and produced *no* text. Before any model output, the workflow switched to the SHA-256 verified official Qwen3-0.6B GGUF, preserving all cases, arms and scoring criteria. Do not claim model results until that workflow actually succeeds and outputs are reviewed.

**Not measured:** long-horizon personality consistency, PersonaForge-style drift, autobiographical fidelity under renderer/model swaps, independent human adjudication, external-world consequences or performance improvement over strong baselines. Production status remains HOLD; exact upstream reproduction and truly independent Pretorius experiments are still required.
