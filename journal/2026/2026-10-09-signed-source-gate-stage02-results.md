# 2026-10-09 — Pretorius firsthand memory Stage 02: signed source custody and query routing

**Status:** Source-integrity engineering PASS on an author-authored test fixture; independent generalization NOT demonstrated, production HOLD.

The Doctor Lives [draft PR #39](https://github.com/Azimn/The-Doctor-Lives/pull/39) extends the Stage 01C autobiographical abstention gate with two research components:

1. A separately held HMAC-SHA256 world receipt authenticated by a synthetic fixture host. Issuer, subject, session, native event ID and key, content digest, and sequence are MAC-covered. Native memory classification is still checked by the earlier `evaluate_firsthand`. No raw receipt or engineering ID becomes first-person experience. A valid test-host eyewitness of a stopped clock is admitted; tampered MACs, revoked records, wrong subjects, sessions, event keys, payload mutation, and model-provided event identifiers fail.
2. A deterministic, conservative classifier for inbound questions that ask Pretorius to remember personal events, versus ordinary factual, third-person, future and fictional requests. It resolves only externally registered exact event aliases and refers ambiguous biography to source review rather than inventing provenance.

A **real first-run failure** was found in [workflow run 38025422569](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38025422569): 'Did you personally meet me?' was incorrectly considered out of scope. Allowing intervening epistemic adverbs corrected it. The [successful rerun 38025467686](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38025467686) passed 9/9 tests and classified all 40 predeclared developer-written questions into the declared classes: 20 firsthand, 15 non-firsthand, 5 ambiguous. Firsthand precision/recall and 3-way accuracy were all 1.0; recorded full result JSON SHA-256 `6a056ea3c7b4ddde2c790097d317d7ce5f9ae31046b19fa0e1cc634fc0a3e82f`, GitHub Actions artifact `11659534333` (90-day retention). This **100% is not independent evidence**: prompts and rules were written by the experiment designer. The caught adverb bypass is evidence of test value and remaining lexical brittleness.

Scientific distinction: UPPB P5's already-existing subjective source-monitoring `doctor_lives/source_monitoring.py` evaluates where a memory *feels* as if it originated from cognitive cues; an HMAC ticket verifies that a controlled host *attested* to a particular source record. Neither proves a true external event without real host authority and a trusted issuer, and neither establishes phenomenal consciousness.

Remaining limitations: host signing key is still in research fixture control; no persistent replay ledger beyond single-call duplicate rejection, no real Evennia/world interface, no verified safe memory inside the deployed engine, and no output-side screening of spontaneous first-person confabulation. An [outbound research PR #40](https://github.com/Azimn/The-Doctor-Lives/pull/40) is the next gated experiment, with new local-model outputs, simulated true-positive events, and false-refusal controls. It must report first-run and any corrected-run errors without treating deterministic abstention as improved identity.
