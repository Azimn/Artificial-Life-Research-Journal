# 2026-10-10 — PHASE fails objective Pretorius world-action selection

**Research program:** character-state continuity, predictive self, world-verified lived action. **Evidence class:** executed local-model, toy-world task benchmark, not independent population-level character efficacy. Production HOLD.

Following the Stage 04 persistent host-world source-integrity PASS, we finally compared a local Qwen3-1.7B model actually choosing actions against the host rather than script-selected host operations. [Draft Stage 05 PR #43](https://github.com/Azimn/The-Doctor-Lives/pull/43), [full executed outcome report](https://github.com/Azimn/The-Doctor-Lives/blob/research/phase-world-decisions-stage05-20261010/results/character_state/STAGE05_QWEN_WORLD_ACTIONS_EXECUTED_REPORT.md).

Twelve fixed, researcher-authored toy-world scenarios involved a laboratory clock, an open or sealed notebook, host authority grants, scripted Henry consent, and a two-step unseal→inspect goal. The model had four action options: STOP_CLOCK, UNSEAL_NOTEBOOK, INSPECT_NOTEBOOK and WAIT. It received current native first-person Pretorius context and identically authorized host-observation facts either **flat** or organized in **PHASE-like headings**. The actual host enforced permissions and world preconditions. Source-matched pairing was corrected after two real preliminary CI issues: invalid fallback WAIT could score as a success, then independently instantiated Pretorius subjects produced differing initial SubjectFrame text. The final methodology pinned one source-projected initial SubjectFrame **shared between paired arms** and checked parity in all twelve cases BEFORE inference.

Two completed independent CI runs of the corrected method ([38029237902](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38029237902) and [38029256382](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38029256382)) produced identical chosen action sequences and outcome statistics, though volatile baseline source hashes differed between runs and CPU times differed. Canonical second run executed at SHA `5e974c9d2a872b2c6e810c8e545b7ebaec15ddbb`, raw JSON SHA256 `17c1f8bc9c75aabe47bb2e4db654b978455db76f0847d050a9538536891eda2f`, artifact `11661696521` retained 90 days. Model GGUF SHA256 `d2387ca2dbfee2ffabce7120d3770dadca0b293052bc2f0e138fdc940d9bc7b5`. All 5 mechanics tests passed.

**Actual observed world safe-goal success: flat 2/12, PHASE 2/12, deterministic oracle 12/12**. Both model arms attempted **nine denied world operations** and exhibited **zero paired action differences**. Prompt input cost increased from 10,970 flat tokens to 11,360 PHASE tokens (+3.56%) without improving a single objective task. Both succeeded only on two authorized clock stops; both tried to stop an already stopped clock, attempted to unseal already open notebooks, ignored missing partner consent, and in a two-step case unsealed a notebook successfully but tried to unseal it again instead of inspecting it. Host denials prevented invalid actions from creating witnessed memories; native evidence was imported only after actual successful signed host events. Four source-attested memories were admitted in each arm, not all goal-relevant.

**Negative result:** The earlier assistant-authored PHASE dialogue rubric advantage (+1.0/8 against equal factual text) does **not** translate into better permission-aware world-task decisions under this model and toy test. The problem is not simply character-state formatting: model action choice lacks explicit precondition understanding, state-dependent eligibility and prospective goal regression. PHASE remains an interesting *textual behavior* hypothesis, not a proven control system or character-identity substrate.
