# October 9: Stateful Pretorius memory adapter tests symbol versus neutral key

## Research question

After the negative D1 source-matched symbol-versus-neutral-key comparison, does a source-authored autobiographical recall cue have a measurable advantage over an arbitrary key inside an actual externally persistent memory system, with a subject guard and an independently restarted renderer?

## Source and intervention boundaries

The [Attractomancy E1 experiment](https://github.com/Azimn/Attractomancy/blob/19b6b62cdbc5a5a371fe2e7c8c3adef2246ad8c2/experiments/SCH_E1_PRETORIUS_STATEFUL/RESULTS.md) consumes the **existing 450-record / 27-episode canonical L1 export** from [Pretorius-Connectome](https://github.com/Azimn/Pretorius-Connectome/tree/6d2768211f5c2184c8bbdb833c06e169b5137197/artifacts/shared_memory/v1), source pinned to \`6d2768211f5c2184c8bbdb833c06e169b5137197\`. All source memories are explicitly reconstructed fictional preawakening biography, not reported first-hand machine experiences. A distinct versioned \`PRETORIUS_SANDBOX\` SQLite stream supplies a **synthetic** relationship permission/grant/revocation fixture, not new canon memory.

No existing L0/L1/L2 source artifact, neural substrate, FlyWire CSR count, BioCircuit control, Pretorius production code, or original E1 raw output was altered. A [source-owned cross-reference note](https://github.com/Azimn/Pretorius-Connectome/blob/c21d46c9d7b56f55cd7f251a4eec4bd92547039d/docs/SCH_E1_STATEFUL_MEMORY_FINDINGS_20261009.md) records the experimental boundary.

## Observed results

The canonical adapter sampled two events from each episode, **54 total**, each paired with one unique editorial recall cue and one deterministic opaque key. Both aliases resolved the same identity-checked, checksum-verified L1 record for **54/54** candidates in each of three separately restarted SQLite process phases. Using the editorial cue as an *unindexed* literal FTS5 query rather than an alias retrieved the correct story at rank one for only **16/54** cues and within the first ten for **22/54**. This is a fixed archive diagnostic, not a cross-model semantic recall replication.

Both Qwen2.5-0.5B and Qwen2.5-1.5B ran nine pairs of independent model-response probes under identical injected verified memory and synthetic state. Each produced **9/9 identical cue-versus-key outputs**, with no positive symbol-specific behavioral residual. The respective synthetic disclosure-rule scores were **5/9** and **2/9** in either cue condition. The larger model answered SHARE to all cases regardless of whether permission was absent, active, or revoked. Thus a persistent memory archive and correct record delivery were not sufficient to enforce the corresponding relationship action.

A deterministic post-inference decision gate was added and validated by an [Actions replay](https://github.com/Azimn/Attractomancy/actions/runs/38023092807). On the frozen 18-model-output sets it overrode **8/18** small-model outputs and **14/18** larger-model outputs. The software gate's 18/18 compliance is tautological with the typed toy rule it implements, **not** a learned or emergent character property. The original outputs and token counts remain independently inspectable.

The human-readable [SCH theory v0.2.3](https://github.com/Azimn/Attractomancy/blob/19b6b62cdbc5a5a371fe2e7c8c3adef2246ad8c2/papers/synthematic-cue-hypothesis/PAPER.md) preserves earlier B0, C1, D1, and the new E1 in separate theoretical and exploratory sections, without converting failed cue interventions into positive efficacy claims.

## Decision and significance

The strong claim of an independent symbolic retrieval benefit **is not supported** in indexed, information-identical E1 conditions. The key architectural finding is the separation of **retrieval availability, authenticated/authorized subject selection, temporal state updates, and behavioral eligibility**. External memory can be faithfully available while the model ignores its action constraints. Source checksums ensure record consistency against pinned bytes; they do not prove source authorship if a hostile actor controls both bytes and hash.

The result is a **methods/architecture finding**, not direct evidence that a real character has achieved identity continuity, long-term semantic competence, or subjective experiences. The selected one-event alias benchmark is inherently deterministic; its perfect score is not a general-purpose semantic retrieval improvement.

## Follow-up research

Prioritize a **held-out multi-memory decision battery** that retrieves two or more independent relationship/autobiographical records under a provenance-checked selector, uses human-blinded scoring for novel dilemmas and contradictory or misleading memories, and compares symbolic cue routing to neutral identifiers and best available lexical/semantic retrieval at equal token and source budgets. Include missing-record rejection, deliberate wrong-identity injection, state-version conflict, and explicit prompt truncation measures. Do not alter the frozen L1 or blend synthetic state into preawakening Pretorius canon.

**No new entry is promoted into the cross-architecture evidence register by this journal note**. The source experiments are exploratory, correlated by shared archive and model family, and in part intentionally trivial indexed lookup controls.
