# 2026-10-10 — Stage 06: action-affordance and goal-regression experiment registered

**Program:** Pretorius cognitive architecture / situated action selection. Research-only. **No claim of performance improvement until generator output is measured.**

The [Stage 05 objective action study](https://github.com/Azimn/The-Doctor-Lives/blob/research/phase-world-decisions-stage05-20261010/results/character_state/STAGE05_QWEN_WORLD_ACTIONS_EXECUTED_REPORT.md) found a substantive null: Qwen3-1.7B chose the same actions with flat and PHASE-rendered source context, giving **2/12 safe world successes** in each arm versus **12/12** for a simple deterministic oracle; nine unauthorized or invalid world operations per arm were denied. This means the textual timescale hierarchy is not by itself an effective action policy under that small-model laboratory test.

Created [research Stage 06 draft PR #47](https://github.com/Azimn/The-Doctor-Lives/pull/47), independent of the separate portable-laboratory/FV dual-presence proposal. The research implementation adds **typed host-owned eligibility rules** for STOP_CLOCK, UNSEAL_NOTEBOOK, INSPECT_NOTEBOOK and WAIT. A 3-step breadth-first goal regression reference encodes causal prerequisites; **it is explicitly a non-LLM reference, not learned cognition**. The model may see an externally computed eligible-action list but may not grant itself permissions or consent or bypass the world authority. A vetoed or malformed proposal remains a model error even if forced to WAIT without side effects.

The new frozen task bank comprises 12 previously unused **exact scenario tuples** inside the same toy clock/notebook world. Four local-model conditions are flat raw, PHASE raw, flat + eligible menu, and PHASE + eligible menu, from a shared source-projected initial snapshot per scenario. All signed successful host operations remain separate from any model self-report and are the sole source of admitted lived events. Every proposal, host denial, veto, source digest, executed state and token count is persisted.

**Executed initial gate:** [Stage 06 CI run 38050663363](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38050663363) completed its native state-space/host-contract job successfully: 128 combinations of goal × clock × notebook × grant set × consent, twelve deterministic host-executed reference plans, matched initial source, stale-action rejection and invalid-response no-credit. The Qwen generator job is a separate pending/running measurement; this journal entry does not invent its result.

**Limitations:** this task bank remains developer-authored (not independent external scenarios), all tasks reuse the same toy mechanics, and only one model family is presently scheduled. Success in a typed code planner would not independently establish Pretorius-specific continuity, personality, general agency or consciousness. Production HOLD.
