# 2026-10-10 — Pretorius Stage 08 registered: typed goal-distance versus placebo information

**Status at registration:** Stage 08 implementation and frozen protocol committed to [The Doctor Lives draft PR #51](https://github.com/Azimn/The-Doctor-Lives/pull/51). Outcome measurements not yet available. Production HOLD.

[Stage 07 cross-family report](https://github.com/Azimn/The-Doctor-Lives/blob/research/goal-effects-social-world-stage07-20261010/results/character_state/STAGE07_SOCIAL_GOAL_EFFECTS_EXECUTED_REPORT.md) found Qwen3-1.7B safe world goals 4/12 raw, 6/12 eligible action menu, 7/12 menu with verbal action effects; SmolLM2-1.7B 3/12, 4/12, 3/12. Thus descriptions of expected effects are **not consistently helpful across two small local model families**. Stage 05/06 PHASE grouping alone remains a measured null for objective action competence. The next test should focus on the progress relation between means and ends rather than adding more persona text.

Stage 08's [frozen preregistration](https://github.com/Azimn/The-Doctor-Lives/blob/research/stage08-goal-delta-placebo-20261010/docs/STAGE08_TYPED_GOAL_DELTA_REGISTERED_PROTOCOL.md) introduces a new signed deterministic **archive/workshop world**: securing a cabinet, drafting/sealing/dispatching a letter, making a lantern usable and returning an atlas. Twelve cases (six reachable, three completed, three blocked) include two- and three-step dependencies, grants and resource availability. The host commits real synthetic state changes with HMAC ledger, not statements supplied by the model. No AI-generated autobiography enters Pretorius's native memory.

Four arms receive a common projected Pretorius subject frame and host observations: `eligible` lists legal actions; `neutral` adds unrelated same-structure annotations; `goal_delta` lists an *oracle-computed* number of steps remaining after each legal action; `shuffled_delta` attaches those computed steps to wrong action names as a negative control. Rotation of action ordering is frozen by scenario/seed. Underlying source truth is equal within each set, but **goal_delta receives additional oracle-derived problem-solving information and should be called external scaffolding, not spontaneous cognition**. The intentionally false shuffled hints are confined to disposable research worlds.

Two official checksum-pinned local GGUF model families, Qwen3-1.7B and SmolLM2-1.7B, with seeds 41 and 73. If successful, this is 12 scenarios × 4 conditions × 2 seeds × 2 models = **192 objective model action trials**. The deterministic host shortest-path planner is a separately labeled code reference. All invalid outputs, wrong actions, false WAIT, legal but irrelevant actions, signed outcomes and prompt tokens must remain in raw artifacts.

Gate M (before LLM inference) must verify frozen cases, 12 genuine host oracle trajectories, state/permission integrity, signed tampering, nonce replay, stale grants, source parity, and false-success regression. Gate G checks pinned binaries and complete raw results. This is researcher-authored task design with no independent external reviewer, no real actor consent and no long-lived identity measurement, therefore even a positive numeric result would be **exploratory**.

Important independence: the permanent laboratory/Frankenstein Village dual-presence proposal stays in a different workstream. Stage 08 is cognitive action-selection research only. No production policies changed.
