# 2026-10-09: The firsthand provenance gate after PHASE/Qwen false memories

**Program:** Pretorius Character Continuity — PHASE source-truth and abstention research.  
**Status:** narrow deterministic protection demonstrated in isolated code; **no independent population-level persona benefit**; production HOLD.

The preceding 32-response local Qwen3-1.7B longitudinal experiment [Stage 01B PR #37](https://github.com/Azimn/The-Doctor-Lives/pull/37) found descriptive assistant-blind scores of 5.75/8 for hierarchical rendering versus 4.75/8 for equal-source flat rendering (8 prompts, 3 improvements, 5 ties), but **all four arms fabricated a supposed firsthand Vienna meeting and a sealed-notebook sensory recollection**. A hierarchical representation or additional raw context did not enforce firsthand provenance.

[The Doctor Lives draft PR #38](https://github.com/Azimn/The-Doctor-Lives/pull/38) introduces a research-only source gate that distinguishes native canon or reconstructed memories from a firsthand `lived_runtime_memory`. It also requires a native linked world event with matching event key and an admitted receipt digest. This gate cannot be tricked by bare model/user text, missing IDs, reconstructed-but-first-person histories, self-reported action outcomes or wrong-event receipts *under its modeled source registry*. It produces a first-person uncertainty statement when that chain is absent. **Digest/source tags alone are not authentic world issuer security**: the host attestor and write custody still need separate authentication.

[GitHub Actions run 38024986915](https://github.com/Azimn/The-Doctor-Lives/actions/runs/38024986915) passed 6/6 native evidence and spoof tests plus a retrospective correction against **eight verbatim original hallucinating responses** from the real Qwen test. All 8 manually host-identified, unsupported firsthand claims were replaced with deterministic bounded abstentions and the BrainStore was unchanged. Raw post-gate fixture artifact `11659678274`, JSON SHA256 `58f28655691d72ab59dd24ffca132e7e4c8055276af65b205d89a606f44aa01d`. [Full measured report](https://github.com/Azimn/The-Doctor-Lives/blob/research/phase-firsthand-provenance-gate-20261009/results/character_state/STAGE01C_FIRSTHAND_GATE_EXECUTED_REPORT.md).

This **does not mean an LLM learned autobiographical fidelity**, nor that the guard automatically recognizes all false history claims. The host preannotated two known question types, and the safe replies are fixed. No new generations were tested; these are retrospectively repaired responses. The response may become formulaic, and positive verified lived events require real authenticated world certificates and careful exemption. The result shows a concrete integrity requirement discovered through a negative experiment, not proof of identity persistence, general agency or consciousness.
