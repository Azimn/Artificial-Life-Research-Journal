# 2026-10-10: Chamber of Echoes — storing episodes stops forgetting, but doesn't produce understanding

**Cumulative predecessor:** [Mnemosyne Pilot16 real original-v783 source](2026-10-09-mnemosyne-associative-memory-review.md), [original committed full case-level evidence](https://github.com/Azimn/Pretorius-Connectome/blob/main/results/imprinting/runs/flywire-pilot16-mnemosyne-run38025454741.json) and ten actual numerical source-bound weights/P checkpoints. The true original 139,255-neuron FlyWire input FEATURE PAIR mask with dense BC01+error-corrective RLS achieved **28/159 familiar trained source literal cue event-ID matches, 7/16 newest, 3/16 earliest and 1/31 old never-presented fourth literal source cue matches**, with native model acceptance only **4/159 correctly accepted familiar while 9/71 absent falsely accepted**. This is weak neural/fly-structural-prior source association, not a working narrative memory.

## Scientific motivation and categorical separation

[Pan et al. (2026)](https://www.biorxiv.org/content/10.64898/2026.08.24.746712v1.full) separate episodic trace allocation from shared slow learned weights; [HiCL (2025)](https://arxiv.org/abs/2508.16651) motivates competitive sparse routing/replay; [Neural Pattern Separation and Completion (2025)](https://arxiv.org/abs/2507.11393) studies discriminating overlapping memories. These are **mechanistic leads, not validated claims about this project**.

The new [source-owned Pilot17 predeclared protocol](https://github.com/Azimn/Pretorius-Connectome/blob/experiment/pilot17-echo-chamber-episodic-routing/docs/PILOT17_CHAMBER_OF_ECHOES.md), [numeric memory implementation](https://github.com/Azimn/Pretorius-Connectome/blob/experiment/pilot17-echo-chamber-episodic-routing/src/pretorius_connectome/echo_chamber17.py) and [five-arm original source study](https://github.com/Azimn/Pretorius-Connectome/blob/experiment/pilot17-echo-chamber-episodic-routing/results/imprinting/PILOT17_SOURCE_RESULTS_PROVISIONAL.md) **deliberately shift architectural category**. It is **EXTERNAL NUMERIC EPISODIC KEY-VALUE RETRIEVAL**, not the fly-derived synaptic W/P learner and NOT biology. Allocated slots directly store the **exact original signed 256D BC01 CONTENT target codeword** per source memory, as well as three compact semantic cue keys originally trained on that specific event. It does not store source-event-ID labels or source narrative text, but internal inference actively retrieves stored numeric CONTENT values by searching those keys. This is not an oracle event-ID database secretly smuggled into a fly neural model; retrieval is an explicit experiment variable. The offline fixed 317 event-ID oracle only scores which original source record its retrieved numerical target represents.

The original 450 canon reconstructed fictional first-person Pretorius source events/27 episodes, unchanged source-L1 and BC01 checksum, episode-split 317 trained/62 validation absent/71 test absent, fixed 159 trained source literal evaluation cases and 31 truly untrained **fourth original literal cues**, frozen local MiniLM original ONNX checksum, three authored first/middle/last training cues, source training stages 0/16/32/64/128/256/317 are unchanged.

The numeric episode array store is **317×(3×64 key features +256 direct stored CONTENT coordinates)=142,016 float32 mutable scalars=568,064 bytes**; a fixed source-independent 256×64 projection adds 16,384 float32 scalars=65,536 bytes, **total 633,600 array bytes**. The original Pilot16 dense W(float32)+P(float64) online ridge state consumes 786,432 bytes, but the architectures differ in algorithms, exact lookup, compute, semantics and true allocated learned capacity. Pretrained MiniLM encoder weights are excluded from BOTH state budgets; byte-count accounting does not alone establish scientifically matched capacity.

Five PREDECLARED equal-array-byte conditions: semantic competitive max of three keys per episode; same keys combined to a normalized centroid; same keys softmax-mixed from top3 source episodic slots at temperature .12; stateless BC01 lexical competing three cue keys; identical semantic keys with deliberately WRONG original source CONTENT targets (historical source nonself rotation). No hyperparameters selected against the old repeatedly used 159/31/71 source probes.

**Strong causal separation and serious limits:** competitive indexing over the original three exact **stored source cue surface forms** prevents catastrophic early literal forgetting; after all 317 episodes the first 16 remain 16/16 compared with 11/16 same-size centroid and just 3/16 in the old shared-W Pilot16 condition. Familiar literal train cue retrieval hits 149/159, compared with the previous 28/159 learned-weight arm. **But this is primarily in-sample numeric retrieval of already stored key→exact target codeword.** The lexical input baseline actually performs 151/159, slightly better on literal recall; stronger pretrained MiniLM semantics does not explain the primary familiar-cue gain. It would be scientifically invalid to write that Pretorius now has semantic autobiographical recall, generalizes paraphrases or that the original FlyWire neural graph outperformed a baseline.

The genuinely **untrained fourth original source cue** result is still just **1/31** for semantic winner-take-one, centroid and soft top3. Worse, the **deliberately WRONG source CONTENT binding condition also gets 1/31 by chance**, so none of this establishes true semantic cue-to-event transfer. The lexical winner-take-one achieved 0/31. These repeated 31 sources have been examined in many preceding pilot experiments; they do not replace a truly independent prospectively blinded human-authored paraphrase battery.

The native key-similarity not-known gate was chosen with **only the distinct 62 validation episode-absent original source cues**, capped at six false accepts there. On the original 159 familiar test and 71 true absent cases, semantic competitor correctly accepts 149/159 exact previously trained cues but wrongly accepts 15/71 absent events, and **correctly accepts ZERO of the 31 genuinely untrained fourth cues**. Centroid decreases absent false acceptance to 10/71 but also only 54/159 correctly accepts familiar. This is neither reliable provenance nor an effective novel semantic cue handler.

## Decisions and next scientific gate

**Result worth keeping:** explicit small episodic trace allocation and winner-take-one competition is a credible memory *storage* mechanism that avoids shared-weight forgetting for exact known cues, at an auditable resource budget. **Result falsified:** pretrained semantic cue vectors plus ordinary cosine key retrieval DO NOT solve novel-surface cue routing or source absence. More snapshots/rehearsal of identical cues is unlikely to solve this alone.

**Prospective next experiment:** train a **small label-free source cue metric adapter using only the three original authored training cue views PER TRAIN episode**, with contrastive positives and different-event negatives, and separate same-byte plain kNN, centroid, trained metric, wrong-target and lexical controls. **Do not tune on the repeatedly used 31 fourth source cues or the 71 absent events**. Quantify whether any unseen original source wording is correctly identified AND accepted and then design a *new sealed independent authored semantic paraphrase panel*. A separate source provenance check still must distinguish the actual Pretorius's factual memories from another archive, independent of any embedding score. If metric learning fails, explicitly report that learned keyed memory is still cue-overfit.
