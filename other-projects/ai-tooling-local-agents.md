# AI Tooling and Local Agent Projects

These projects are tracked as engineering infrastructure unless a specific experiment promotes part of them into the core research journal.

## OPJ-TOOL-001: AliceMod

Desktop companion and agent shell combining local or cloud models with speech-to-text, text-to-speech, memory, vision, tools, MCP integration, scheduling, and desktop interaction.

Repository: `AliceMod`.

## OPJ-TOOL-002: rho

Persistent local-first agent runtime explored as lightweight infrastructure for running AI locally.

Repository: `rho`.

## OPJ-TOOL-003: openclaw

Agent-platform and autonomous-build-loop experimentation.

Repository: `openclaw`.

Some OpenClaw work intersects the Kiki organism project, but the platform itself remains tooling.

## OPJ-TOOL-004: picoclaw

Ultra-lightweight Go-based agent/runtime exploration.

Repository: `picoclaw`.

## OPJ-TOOL-005: ClawPhone

Android and Termux deployment experiments for local agent tooling.

Repository: `ClawPhone`.

## OPJ-TOOL-006: 01_lite_JR

AI-device and hardware-reference exploration.

Repository: `01_lite_JR`.

## OPJ-TOOL-007: Flowise experiments

Workflow and agent-composition exploration using Flowise.

Repository: `Flowise`.

## Boundary with the core journal

When these platforms are used to test persistent identity or organism mechanisms, the experiment belongs in the core ledger while the general platform engineering remains here.
